# Roadmap

For users of the public GuliweRR release. Current work:

- **Inverse module** — a graphical mode-association tool.
- **Spot-averaged maps** — calibration against measured TGS and SRAS maps.
- **Surface-wave classification** — Love-type modes and more film/substrate systems.
- **SRAS** — a module for polycrystalline samples.

The Julia version follows every MATLAB change, one to one.
